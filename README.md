## How to deploy on GitHub Pages

### Option A — Quickest (upload via browser)

1. Go to [github.com](https://github.com) and sign in
2. Click **New repository**
3. Name it exactly: `edmarocampo.github.io` (replace `edmarocampo` with your GitHub username)
4. Set it to **Public**
5. Click **Create repository**
6. Click **uploading an existing file**
7. Drag and drop all files from this folder (`index.html`, `README.md`, `.nojekyll`)
8. Click **Commit changes**
9. Go to **Settings → Pages → Source → Deploy from branch → main / root**
10. Your site will be live at `https://edmarocampo.github.io` within 1–2 minutes ✅

### Option B — Using Git CLI

```bash
git init
git add .
git commit -m "Initial portfolio deployment"
git remote add origin https://github.com/edmarocampo/edmarocampo.github.io.git
git push -u origin main
```

## Updating your GitHub username in the site

Open `index.html` and find/replace `edmarocampo` with your actual GitHub username in these lines:

```html
<link rel="canonical" href="https://YOUR_USERNAME.github.io/" />
<meta property="og:url" content="https://YOUR_USERNAME.github.io/" />
```
